?? Postman Setup Instructions

Open Postman Application
Click on "Environments" in the left sidebar
Click the "+" button to create new environment
Set Environment name as "AMS Development"
Add all variables from the table above
Click "Save" to save the environment
Select "AMS Development" from environment dropdown

?? Usage Examples

In Request URLs:

{{baseUrl}}/api/Auth/register
{{baseUrl}}/api/Course/{{courseId}}
{{baseUrl}}/api/Class/{{classId}}/enroll/{{studentId}}

In Request Headers:

Authorization: Bearer {{adminToken}}
Authorization: Bearer {{instructorToken}}
Authorization: Bearer {{studentToken}}

In Request Body:

{
  "courseId": {{courseId}},
  "classId": {{classId}},
  "assignmentId": {{assignmentId}}
}

? Auto-Set Values with Test Scripts

Add this script to the "Tests" tab of your requests to automatically set variables:

// Auto-set token from login response
if (pm.response.code === 200) {
  const response = pm.response.json();
  if (response.data.token) {
    pm.environment.set('adminToken', response.data.token);
  }
  if (response.data.id) {
    pm.environment.set('courseId', response.data.id);
  }
}
?? Important Notes:
• Make sure your API is running on http://localhost:5281
• Tokens will expire - you'll need to re-login periodically
• Set the environment as active before running tests
• Variables marked as (empty) will be filled during testing
